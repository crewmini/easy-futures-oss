# PRD — easy-futures (어르신용 쉬운 선물 거래 앱)

## 1. 사용자와 문제
- 사용자: 40~70대. 스마트폰은 쓰지만 거래소 앱의 작은 글씨·영문·전문용어·복잡한 주문창이 장벽.
- 문제: 롱/숏, 레버리지, 손절, 평단 개념을 알아도 **어느 버튼이 그것인지** 찾기 어렵고, 실수 주문이 두렵다.
- 목표: "오른다/내린다 → 얼마 → 몇 배 → 손절선" 네 번의 큰 버튼 터치로 주문이 끝나고, 내 상태(포지션)가 한눈에 보이는 앱.

## 2. 범위 (MVP)
- 거래소: WOO X Pro 무기한 선물 (USDT 마진). 종목: BTCUSDT, ETHUSDT 두 개만.
- 플랫폼: 모바일 Chrome PWA (홈 화면에 추가 → 앱처럼 실행). iOS Safari도 동작하되 2순위.
- 계정: 다중 사용자(최대 300명). 아이디+비밀번호 로그인(초대 코드로 가입), 각자 WOO X Pro API 키를 앱에서 한 번 등록(가족이 대신 해줄 수 있음). 서버는 Cloudflare Workers.
- 모드: **실거래 모드**만. 가입 → 신분증 확인(관리자 승인) → 거래소 API 키 연결 → 주문. 그 전에는 홈에 온보딩 카드("실거래 준비")만 보이고 주문·자동매매·따라하기 불가. (2026-09-18: 연습 모드는 제품에서 제거. 연습 엔진은 시세 피드·테스트·관리자 전용으로만 남는다.)

## 3. 화면 구성 (단일 화면 + 시트)
### 3.1 홈 (내 상태)
1. 종목 토글: [비트코인] [이더리움] — 큰 두 버튼.
2. 현재가: 화면에서 가장 큰 숫자. 상승 빨강/하락 파랑(국내 관행) + "▲ 올랐어요 / ▼ 내렸어요" 글자 병기.
3. 내 지갑: "쓸 수 있는 돈 1,234 USDT (≈ 170만 원)". 환율은 표시용.
4. 포지션 카드 (없으면 "지금은 아무것도 걸어두지 않았어요"):
   - 방향 문장: "비트코인이 **오른다**에 걸었어요 (5배)"
   - 가격 사다리(핵심 시각화): 세로/가로 눈금 위에 강제정리가 ─ 손절가 ─ **산 가격(평단)** ─ 현재가 ─ 익절가 를 색 점으로 배치. 현재가가 산 가격 대비 어느 쪽에 있는지 즉시 보임.
   - "지금 팔면: +12,300원 (+3.2%)" 큰 글씨.
   - 물량: "0.05 BTC (50계약) / 내 돈 100 USDT 사용 중"
   - 버튼: [손절가 바꾸기] [익절가 바꾸기] [전부 정리하기(빨강, 2단계 확인)]
5. 맨 아래 큰 버튼: [새로 걸기]

### 3.2 주문 시트 (새로 걸기) — 4단계 위저드, 한 화면에 한 질문
1. "어느 쪽에 거시겠어요?" → [오른다 📈] [내린다 📉]
2. "얼마를 거시겠어요?" → 프리셋 [50] [100] [300] [500] USDT + 직접 입력. 하단에 "쓸 수 있는 돈 1,234 USDT".
3. "몇 배로 하시겠어요?" → [1배] [2배] [3배] [5배] [10배]. 각 버튼 밑에 "가격이 1% 움직이면 내 돈의 N% 변동". 상한(10배) 이상은 설정에서만 해제.
4. "얼마나 떨어지면 자동으로 정리할까요? (손절)" → [-2%] [-3%] [-5%] [-10%] → 계산된 손절가 표시. 익절은 "익절도 걸기" 토글(기본 꺼짐).
5. 확인 화면: 한 문단 요약. "비트코인이 오른다에 100 USDT를 5배로 겁니다. 시장가로 사고, 95,200 달러 아래로 내려가면 자동으로 정리합니다(손절). 강제정리 가격은 약 87,000 달러입니다." → [네, 주문합니다] (길게 누르기 1.5초) / [아니요]
6. 결과: "주문이 들어갔어요 ✅ 산 가격 96,010 달러" + 진동.

### 3.3 설정
- 글자 크기 [보통] [크게] [아주 크게] (rem 스케일 1.0/1.25/1.5)
- 레버리지 상한, 1회 최대 금액, PIN 변경. (관리자 계정만 모드 [연습] [실거래] 토글이 보인다)
- 연결 상태: 거래소 API 정상/오류, 서버 시간 차이

## 4. 비기능 요구
- 접근성: 최소 폰트 20px, 터치 타겟 56px, 대비 WCAG AA, 색+글자 병기, 애니메이션 최소.
- 성능: 첫 로드 < 2s(4G), 시세 갱신 1초 이내(공개 WS 직결).
- 안정성: 서버 재시작·네트워크 끊김 시 화면에 "연결 끊김 — 다시 연결 중" 배너. 끊긴 동안 주문 버튼 비활성.
- 보안: 서버 `.env` 외 키 저장 금지, 서버 IP를 WOO X Pro API 키에 바인딩, PIN 5회 실패 시 10분 잠금.

## 5. 아키텍처
`docs/architecture.md` 참고 (Cloudflare Workers + D1 + Durable Object, 사용자별 키로 거래소 직행).

## 6. 성공 기준
- 실사용자(부모님 등) 1명이 설명 없이 온보딩(신분증·API 키)을 마치고 최소 수량(1계약)으로 진입→손절 수정→정리까지 완료.
- 실거래 1계약 주문·TP/SL·정리 왕복이 서버 로그와 거래소 화면에서 일치.

## 7. 이후 (MVP 밖)
종목 확장, 원화 환산 실시간, 알림(가격 도달·손절 체결 푸시), 가족 보호자 모드(주문 알림 공유), 다중 사용자.
