고수 따라하기가 뭔가요?

내가 내 계좌에서 사고팔면, 나를 따르기로 한 사람(팔로워)의 계좌에서 같은 방향·비례 크기로 거의 동시에 사고팔립니다.

1. 내가 내 계좌에서 매매거래소 앱이든 Easy futures든 상관없음
→
2. 서버가 1~2초 안에 감지거래소 개인 알림 + 2초마다 확인
→
3. 팔로워 계좌에 비례 복제내 자산의 N% → 팔로워 "따라갈 돈"의 N%
→
4. 손절·익절·배율 변경도 그대로내가 바꾸면 팔로워도 바로 바뀜
✔ 내 API 키는 읽기(포지션 조회)에만 씁니다. 서비스가 내 계좌로 주문을 내는 일은 절대 없습니다.
✔ 고수 활동에 보수는 없습니다. 팔로워에게 수익을 약속하거나 개별로 권유하면 안 됩니다.
✔ 팔로워의 손익은 팔로워 몫입니다. 다만 조작·허위 소개 등 고의로 손해를 입히면 고수가 책임집니다.

고수가 될 수 있는 사람 — 조건 3가지

세 가지가 모두 ✅ 여야 "고수 신청하기" 버튼이 눌립니다. 부족한 것은 신청 카드 안의 버튼으로 바로 채울 수 있습니다.

  1. 신분증 확인 완료 ✅ — 설정 → 실거래 준비 → 신분증 확인하기. 담당자가 확인하면 "완료"로 바뀝니다.
  2. 거래소 API 키 연결됨 — 설정 → 거래소 연결하기. 권한은 Read-Only + Future-Trade, 출금 권한은 절대 주지 않기.
  3. 고수 약관 동의 — 신청 카드에서 끝까지 읽고 체크.
팔로워에게 전달되는 것은 진짜 계좌의 진짜 매매뿐입니다. 신분증과 API 키가 없으면(홈의 "실거래 준비" 카드가 남아 있으면) 내 매매도 감지되지 않습니다.

복제되지 않는 것 · 안전장치

내 계좌는 건드리지 않습니다

API 키는 포지션 조회(읽기)에만 씁니다. 서비스가 내 계좌로 주문·정리·출금을 하는 일은 없습니다. 출금 권한 없는 키만 연결하세요.

팔로워가 직접 잡은 포지션도 건드리지 않습니다

팔로워 계좌에서 "나를 따라 들어간 수량"만 장부로 관리합니다. 정리할 때도 장부 수량만 정리하고, 같은 종목에 반대 방향을 들고 있으면 건너뜁니다.

손절 없이는 진입하지 않습니다

내 손절가가 있으면 팔로워도 같은 가격. 내가 손절을 안 걸었으면 팔로워가 정한 손절 %(내 돈 기준, 기본 -30%)가 대신 붙습니다.

팔로워마다 손실 한도가 있습니다

"여기까지 잃으면 멈추기"(따라갈 돈의 N%, 기본 50%)에 닿으면 그 팔로워만 멈추고 전부 정리합니다. 다른 팔로워와 나에겐 영향 없습니다.

팔로워 잔고가 적으면 "금액이 너무 적음"으로 건너뜁니다. 비트코인은 1계약(≈ 79 USDT)이 최소라서 소액 팔로워는 비트코인만 빠질 수 있습니다.

팔로워를 위해 고수가 지키면 좋은 것

1. "얼마"가 아니라 "몇 %"가 전달됩니다

내 계좌가 500이든 50,000 USDT든 팔로워는 내 자산 대비 비율로 따라옵니다. 내 돈의 50%를 한 번에 넣으면 팔로워도 50%를 넣습니다. 한 번에 10~20%씩이 안전합니다.

2. 손절은 항상 걸어 두세요

내 손절가가 있으면 팔로워도 똑같은 손절가를 갖습니다. 없으면 팔로워마다 다른 손절 %가 붙어 결과가 제각각이 됩니다.

3. 배율은 낮게

팔로워 최대 배율은 기본 10배. 내가 20배를 쓰면 팔로워는 10배로 잘려 포지션이 내 것의 절반 크기가 되고 손익률도 달라집니다.

4. 잘게 쪼개 사고팔면 팔로워 수수료가 늘어납니다

내 계좌의 변화 하나하나가 팔로워 계좌의 주문이 됩니다. 소액 팔로워는 계약 수가 0으로 내림돼 "금액이 너무 적음"으로 빠질 수 있습니다.

5. 방향을 급히 바꾸면 두 번 전달됩니다

오른다 → 내린다로 뒤집으면 팔로워는 "정리" 후 "진입" 두 번 체결됩니다. 급변 때는 나보다 나쁜 가격에 잡힐 수 있습니다.

"내 팔로워"에 건너뜀·실패가 자꾸 보이면 이유를 읽어 보세요. 잔고 부족, 반대 포지션 보유, 손절이 이미 지나감이 대부분입니다.

고수 활동 체크리스트

  1. 신분증 확인이 "완료 ✅"다
  2. 신분증·거래소 API 키(출금 권한 없음)가 "연결됨"이고 홈의 "실거래 준비" 카드가 사라졌다
  3. 👥 고수 따라하기 탭 → "고수로 활동하기"에서 닉네임·소개를 쓰고 고수 약관을 끝까지 읽고 신청했다
  4. 담당자 승인 뒤 "나는 고수예요" 카드와 "내 팔로워" 화면이 보인다
  5. "내 팔로워"에 🟢 감시 연결 정상이 보인다
  6. 매매할 때 손절을 항상 걸고, 한 번에 자산의 10~20%씩만 쓴다
  7. 팔로워에게 개별 연락·권유·수익 약속을 하지 않는다
  8. API 키를 지우면 고수 활동이 멈춘다는 것을 안다
