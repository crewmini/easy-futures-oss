고수 따라하기가 뭔가요?

잘하는 사람(고수)을 고르고 "따라갈 돈"을 정하면, 고수가 사고팔 때마다 내 계좌에서 내가 정한 돈만큼 비례해서 똑같이 사고팝니다.

1. 고수를 고른다30일 수익률 · 승률 · 최근 거래 보고
→
2. 따라갈 돈·한도를 정한다얼마까지 · 얼마 잃으면 멈출지
→
3. 고수가 사고팔면 나도1~2초 안에 · 손절 항상 붙음
→
4. 언제든 멈춘다길게 눌러 그만 따라가기
✔ 손절은 항상 붙습니다. 고수의 손절가가 있으면 같은 값, 없으면 내가 정한 손절 %가 붙습니다.
✔ "여기까지 잃으면 멈추기"에 닿으면 자동으로 멈추고 전부 정리합니다. 폰을 꺼 둬도 됩니다.
✔ 고수가 틀리면 나도 잃습니다. 이익도 손실도 본인 것입니다. 감당할 만큼만 넣으세요.

2신분증 확인 → 거래소 연결

홈의 "실거래 준비" 카드(또는 설정)에서 합니다. 둘 다 끝나야 고수를 따라갈 수 있습니다.

① 신분증 확인 (필수)

  1. 홈 "실거래 준비" 카드(또는 설정) → 신분증 확인하기
  2. 주민등록증·운전면허증·여권 중 하나, 본인 것만
  3. 뒷자리 7자리는 가리고 선명하게 찍기 → "제출하기"
  4. 담당자가 확인하면 "완료 ✅" (보통 하루 안)
키는 서버에 암호화 보관되고 폰에 내려오지 않습니다. 키를 지우면 따라하기는 자동으로 멈춥니다 (13쪽).

② 거래소 API 키 연결 (필수)

  1. WOO X Pro → API 관리 → 새 키. 권한 Read-Only ✔ Future-Trade ✔ 출금 ✘, IP 제한 없음
  2. 홈 카드(또는 설정) → "거래소 연결하기" → Access·Secret·Memo 붙여넣기 → "연결됨"
둘 다 끝나면 홈의 "실거래 준비" 카드가 사라지고 화면 위에 빨간 "실거래" 표시가 보입니다. 이제부터 진짜 돈입니다 — 👥 고수 따라하기 탭에서 고수를 고르세요.

"자세히 보기 →"를 누르면 고수 자세히 보기 화면이 열립니다. 위에서부터 소개 → 성적 → 최근 마감 거래 → 따라하기 폼 순서입니다.

최근 마감 거래 (고수가 건 돈 기준 %)

최근 10건. 종목 · 오른다/내린다 · 언제 · +8.2% 이익 / -3.0% 손실 / 본전. 금액이 아니라 고수가 그 거래에 건 돈 대비 %라서, 같은 비율로 따라갔다면 내 돈도 비슷한 %로 움직였을 거란 뜻입니다.

화면 문구: "수량·금액은 공개하지 않아요. 과거 성적은 앞으로의 결과를 보장하지 않아요."

이런 고수는 조심

  • 거래 수가 1~2번인데 수익률만 높다
  • 최근 마감 거래에 -30% 이상 손실이 자주 보인다 (손절을 늦게 건다는 뜻)
  • 소개에 "확실", "보장", "무조건" 같은 말이 있다 (약관 위반)
  • 들고 있는 종목이 매번 3개 다 있다 (한 번에 많이 거는 사람)
