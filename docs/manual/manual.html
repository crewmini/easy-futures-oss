담당자의 봇이 "여기가 바닥"이라고 찾으면, 담당자가 확인을 누르고, 내 계좌에서 자동으로 "오른다"에 걸립니다.

3. 내 계좌에 자동 주문내 돈의 N%, 손절 항상 붙음

✔ 진짜 돈이 나갑니다. 이익도 손실도 본인 것입니다. 감당할 만큼만 넣으세요.

3신분증 확인 (3분 + 담당자 승인)

주문과 AI 자동매매는 본인 확인이 끝나야 열립니다. 홈의 "실거래 준비" 카드(또는 설정 → 실거래 준비) → 신분증 확인하기.

  1. 신분증 종류 고르기: 주민등록증 · 운전면허증 · 여권
  2. "사진 찍기 / 고르기" → 카메라로 찍거나 보관함에서 선택
  3. 이름·생년월일·발급일이 선명하게 보이게. 빛 반사 없게
  4. 주민등록번호 뒷자리 7자리는 손가락이나 종이로 가리고 찍으세요 (법에 따라 뒷자리는 받지 않습니다)
  5. "제출하기" → 담당자가 확인하면 "완료 ✅"로 바뀝니다 (보통 하루 안)
타인의 신분증을 쓰면 형사 처벌 대상이고, 모든 손해를 본인이 집니다. 반드시 본인 것만.

4거래소 연결 — API 키 만들기 (5분)

API 키는 "내 계좌에서 주문만 낼 수 있는 열쇠"입니다. 출금 권한은 절대 주지 마세요.

① WOO X Pro 에서 키 만들기

  1. WOO X Pro 앱/사이트 → 내 정보 → API 관리 → "새 API 키"
  2. 권한: Read-Only ✔, Future-Trade ✔. Withdraw(출금)는 ✘
  3. IP 제한: 설정하지 않음 (서버 주소가 바뀌기 때문)
  4. 만들면 Access Key · Secret Key · Memo 세 가지가 나옵니다. Secret Key 는 이때 딱 한 번만 보이니 바로 복사

② Easy futures 에 넣기

  1. 홈의 "실거래 준비" 카드(또는 설정) → "거래소 연결하기"
  2. Access Key · Secret Key · Memo 를 붙여넣기
  3. "연결하기" → 서버가 거래소에 확인해 보고 "연결됨"으로 바뀝니다
키는 서버에 암호화해서 보관되고 폰에는 절대 내려오지 않습니다. 키를 지우면 자동매매도 같이 꺼집니다.

화면 미리 익히기 — "내 상태" 게이지 읽는 법

연습 모드가 없으니 걸기 전에 화면부터 익혀 두세요. 자동매매가 잡은 포지션도 같은 게이지로 보입니다.

  1. 홈 아래 "＋ 새로 걸기" (자동매매만 쓸 거면 안 눌러도 됩니다)
  2. 오른다 / 내린다 고르기
  3. 금액: 버튼(10%·25%…)이나 막대로 내 돈의 몇 %를 쓸지
  4. 배율: 2~10배 권장. 배율만큼 이익도 손해도 커집니다
  5. 손절가·익절가: "내 돈 기준 -10% / +20%" 같은 버튼으로. 손절은 필수
  6. 요약 문장 확인 → 버튼을 길게 눌러 주문 (실수 방지)
처음 직접 걸어 본다면 1계약(가장 작은 금액)으로만 — 손해도 진짜 돈입니다.

"내 상태" 게이지 읽는 법

익절가 — 여기 오면 이익 확정산 가격(평단) — 지금 가격 알약이 여기 근처에서 움직임손절가 — 여기 오면 손실 확정강제정리가 — 거래소가 강제로 정리하는 선

빨강 = 오른다·이익, 파랑 = 내린다·손해 (국내 방식). "지금 팔면 손익"이 원화로도 표시됩니다.

6AI 자동매매 신청 (5분 + 결제·승인)

홈 위쪽 "🤖 AI 자동매매" 탭 → 신청 카드. 세 가지만 정하면 됩니다.

  1. 신호 1건에 내 돈의 몇 % (5·10·20·30%). 최대가 30%인 이유: 봇은 저점마다 최대 3번 나눠 들어가서, 30%면 한 흐름에 최대 90%까지 쓰입니다
  2. 최대 배율 (막대로 1~50배). 처음엔 3~5배를 권합니다. 신호가 더 높은 배율을 요청해도 이 값을 넘지 않습니다
  3. 기본 손절 (내 돈 기준 -5~-30%). 신호에 손절이 없을 때만 쓰이는 안전망
  4. 자동매매 특약을 끝까지 내려 읽으면 동의 칸이 열립니다 → 체크 → "신청하기"
  5. 담당자에게 이용료 결제 → 담당자가 확인하고 승인 → 화면이 "꺼져 있어요"로 바뀝니다 (이제 켤 수 있음)

예: 잔고 100 USDT, 30%, 최대 5배

1번 저점 진입30 USDT × 3배
2번 저점 불타기+ 30 USDT
3번 저점 불타기+ 30 USDT
최대 투입90 USDT (남는 돈 10)

봇이 보내는 배율(기본 3배)과 내 최대 배율 중 낮은 쪽이 쓰입니다.

어떻게 진입되나요? — "3의 법칙"

바닥을 찍은 뒤 저점이 점점 높아지는 모양(1번 → 2번 → 3번)을 잡아 오른다에 겁니다. 봇이 후보를 내고, 사람이 확인합니다.

📉 1번 저점 확정 ✅오른다 진입 · 손절 = 1번 저가 × 0.995
→
📉 2번 저점(더 높음) ✅불타기 · 손절을 2번 저점으로 올림
→
📉 3번 저점 ✅불타기 · 손절 또 상향 · 여기서 끝
→
📈 오르면익절가 도달 시 자동 정리

내려가면?

2·3번 저점 아래로 마감지금 가격에 전량 정리
1번 저점 아래로 마감전량 정리
손절가 도달거래소가 자동 정리

저점이 깨지면 손절가(0.5% 아래)를 기다리지 않고 바로 정리해서 손실을 줄입니다. 담당자가 3분 안에 "무시"를 누르면 유지됩니다.

익절은 얼마에?

손절까지 거리의 1.5배. 예) 저점보다 2% 위에서 확정되면 손절 -2.5%, 익절 +3.7% (10배면 내 돈 기준 +37%).

봇은 15분봉만 씁니다. 후보가 자주 뜨지만, 담당자가 차트·거래량을 보고 ✅/❌를 고릅니다. ❌면 아무 일도 없습니다.

전부 잃을 수 있습니다. 배율 거래는 가격이 조금만 반대로 가도 손실이 크고, 강제정리가 날 수 있습니다. 생활비·빌린 돈은 절대 넣지 마세요.
봇은 틀릴 수 있고, 늦을 수 있고, 멈출 수 있습니다. 수익을 보장하지 않습니다. 담당자의 ✅도 판단이지 예언이 아닙니다.
한 흐름에 최대 3번 진입 → 신호당 30%면 최대 90%까지 들어갑니다. 비율을 정할 때 이걸 생각하세요.

안전장치 (전부 자동)

  • 손절 없는 주문은 서버가 내보내지 않음
  • 손절가가 강제정리 밖이면 내 돈 기준 손절로 대체
  • 저점이 이미 깨진 뒤의 늦은 ✅는 실행 안 함
  • 시세가 30초 넘게 끊기면 실행 안 함
  • 1회 최대 금액(설정)을 넘지 않음
  • 키 삭제·신분증 거절 시 자동으로 꺼짐
  • 비상 버튼 = 끄기 + 전부 정리

자주 묻는 질문

신호가 왔다는데 내 계좌엔 왜 없죠?

"내 자동매매 기록"의 오른쪽 상태를 보세요. 건너뜀이면 이유가 적혀 있습니다: 잔고 부족(금액이 너무 적음), 꺼져 있음, 손절가를 이미 지나침, 반대 포지션 보유 중.

2번·3번은 담당자가 안 눌러도 들어가나요?

네. 1번만 담당자가 직접 확인하고, 2번·3번 불타기는 봇이 찾은 뒤 3분 안에 담당자가 막지 않으면 자동으로 들어갑니다. 저점이 깨질 때의 정리도 같은 방식입니다.

앱을 꺼도 되나요? 폰이 꺼지면요?

됩니다. 서버가 24시간 돌립니다. 폰은 확인용입니다.

거래소 앱에서 TP/SL 칸이 비어 있어요

우리 손절·익절은 "Open Orders(미체결 주문)"에 플랜 주문으로 들어갑니다. 종목당 2개(손절·익절)가 보이면 정상입니다.

중간에 그만두고 싶어요

AI 자동매매 탭에서 "끄기". 걸어둔 것까지 정리하려면 "비상" 또는 "전부 정리하기". 아무 때나 됩니다.

문제가 생기면요?

담당자에게 연락하세요. 담당자는 내 화면과 같은 걸 보고 도와줄 수 있습니다. 급하면 거래소 앱에서 직접 정리해도 됩니다.

시작 전 체크리스트

  1. easyfutures.app 가입하고 홈 화면에 추가했다
  2. 신분증 확인이 "완료 ✅"다

  7. AI 자동매매 신청 → 결제 → 승인 → 길게 눌러 켰다 (🟢)
